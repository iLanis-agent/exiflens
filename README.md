# ExifLens

See what your photos reveal before you share them. Open `app.html`, drop a JPEG (or pick a built-in preset), and get:

- a **"what this photo reveals"** panel - exact GPS location (with map link), camera serial number, exact time taken, software - the fields people usually don't know they're publishing
- full metadata: camera, exposure (with APEX cross-checks), dates, GPS (decimal degrees + signed altitude), file/container facts
- 100% local: parsing runs in your browser (`engine.js`, no dependencies), the photo is never uploaded

## Live

https://ilanis-agent.github.io/exiflens/

## Format support

JPEG files with an EXIF APP1 segment. Both TIFF byte orders (II little-endian, MM big-endian). Decodes ASCII, SHORT, LONG, RATIONAL, SRATIONAL, BYTE and UNDEFINED tag types across IFD0, the Exif sub-IFD (0x8769) and the GPS sub-IFD (0x8825). Maker notes, embedded thumbnails, HEIC/PNG/TIFF/RAW and FLOAT/DOUBLE types are not handled.

## Tests

```
node tests/run_tests.js
```

Runs the shared engine over `tests/corpus/*.jpg` and compares every field against `tests/expected.json`, generated by `tests/oracle.py` using the real [exifread](https://github.com/ianare/exif-py) library (`python3 tests/oracle.py`, needs `pip install exifread piexif pillow`). GPS-decimal and APEX (shutter/aperture) conversions are verified independently in plain Python. 90 assertions, all passing.

The corpus covers: a full Canon file with GPS (N/E refs), an iPhone file with S/W refs and below-sea-level altitude, a minimal Make/Model file, hand-crafted big-endian and little-endian files with signed rationals, and a JPEG with no EXIF at all.

### Testing deviations (disclosed)

- Corpus photos are synthetic solid-color JPEGs generated with Pillow/piexif; EXIF payloads are real piexif output (plus two hand-crafted TIFF payloads for the endianness cases), and the oracle reads the real files.
- exifread normalizes rationals to lowest terms; the engine reduces fractions with GCD to match, and the expected values are the oracle's reduced forms.
